# Animating DW-NOMINATE scores with gganimate

These animations show how the ideological distributions of Democrats and
Republicans changed across postwar Congresses. The House and Senate appear in
separate panels. One animation shows the distribution of first-dimension
DW-NOMINATE scores by party. The other plots individual members on both
dimensions.

See [the animations and Adam Olson's explanation][article].
The [R script](main.r) reads member scores from Voteview and draws both charts.
The [output directory](output/) contains the original GIFs.

[article]: https://adamolson.org/blog/animating-dw-nominate-with-gganimate/
